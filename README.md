# เสี่ยแพค — barbershopweb

เว็บจองคิวตัดผมและหลังบ้านสำหรับดู/เรียกคิวของร้าน **เสี่ยแพค**
แยกเป็น **2 ไฟล์ HTML แบบ self-contained** คือหน้าลูกค้าและหลังบ้าน
โดย CSS และ JavaScript ถูกฝังอยู่ในไฟล์ของแต่ละหน้า และใช้ API/SSE ร่วมกันเพื่อให้สองหน้าซิงก์กัน
ใช้ HTML, CSS, JavaScript และ Node.js ล้วน ไม่ต้องติดตั้ง dependency เพิ่ม

## เริ่มใช้งาน

ต้องมี Node.js (แนะนำ v18 ขึ้นไป) แล้วรัน:

```bash
cd barbershopweb
npm start
```

หรือ

```bash
node server.js
```

หน้าเว็บลูกค้า: `http://localhost:8001/`
หลังบ้าน: `http://localhost:8001/admin`
ข้อมูลการจองเก็บที่ `data/bookings.json` (สร้างอัตโนมัติ)

> ต้องรัน `server.js` ไว้เสมอ เพราะคิว เรียลไทม์ และการแจ้งเตือนต้องใช้ API

เปลี่ยนพอร์ตได้ เช่น:

```bash
PORT=8001 npm start
```

## หน้าเว็บลูกค้า

- ราคาตัดผมเดียว **50 บาท**
- กรอกแค่ **ชื่อเล่น**, **ชั้น** และ **เบอร์โทรศัพท์**
- ตารางคิว 7 วัน แบบตารางเรียน/ปฏิทิน เลื่อนดูสัปดาห์ถัดไปได้
- แสดงสถานะ **ว่าง / มีคิว / เลยเวลา / ปิด**
- แตะช่อง “ว่าง” เพื่อเลือกวันและเวลาทันที
- **1 ช่วงเวลา 30 นาที รับได้ 1 คน** ตรวจสอบที่เซิร์ฟเวอร์ จึงจองซ้ำจากคนละเครื่องไม่ได้
- มีแบนเนอร์ **คิวปัจจุบัน** อัปเดตแบบเรียลไทม์เมื่อหลังบ้านกดเรียกคิว
- แสดง **เวลาปัจจุบันแบบเรียลไทม์** ซิงก์เวลาจากเซิร์ฟเวอร์
- หลังจองมี **คิวของฉัน** แสดงคิวที่รออยู่ และแจ้งเตือนเมื่อถูกเรียกคิว
- มีเสียงแจ้งเตือน + ข้อความบนหน้าเว็บ และ Browser Notification หากอนุญาต

## หลังบ้านร้าน

เปิดที่ `http://localhost:8001/admin` โดยตรง
หน้าลูกค้าไม่มีลิงก์หรือปุ่มไปยังหลังบ้าน

- **ไม่มี PIN** เปิดดูและกดเรียกคิวได้ทันที
- แสดงว่าถึงคิวที่เท่าไรแล้ว และคิวปัจจุบันเป็นของใคร
- แสดงคิวถัดไป เวลา ชื่อเล่น ชั้น เบอร์โทรศัพท์ และรหัสการจอง
- เบอร์โทรศัพท์แสดงเป็นลิงก์กดโทรได้
- กดปุ่ม **“เรียกคิวต่อไป”** เพื่อเลื่อนคิวถัดไป
- หน้าเว็บลูกค้าจะเห็นคิวปัจจุบันเปลี่ยนทันที
- ระบบเก็บสถานะคิวไว้ที่เซิร์ฟเวอร์ รีเฟรชหรือเปิดใหม่ก็ยังอยู่
- มีนาฬิกาเวลาร้านเดินวินาทีต่อวินาที
- อัปเดตแบบเรียลไทม์ทันทีเมื่อมีลูกค้าจองหรือกดเรียกคิว
- ใช้ระบบแจ้งเตือนผ่านเบราว์เซอร์ (ต้องเปิดหน้านี้ไว้และกดอนุญาตการแจ้งเตือน)

> หลังบ้านไม่มีรหัสผ่านตามที่ต้องการ จึงควรจำกัดการเข้าถึงเฉพาะเครื่องหรือเครือข่ายของร้าน และระวังข้อมูลเบอร์โทรศัพท์ของลูกค้า

## เข้าจากอุปกรณ์อื่น

เซิร์ฟเวอร์ผูกกับ `0.0.0.0` จึงเข้าจากมือถือหรือคอมพิวเตอร์เครื่องอื่นในวงเดียวกันได้ที่:

```text
http://<IP ของเครื่องที่รันเซิร์ฟเวอร์>:8001
```

เช่น `http://100.77.227.117:8001` หรือ `http://173.20.197.156:8001`
หน้าเว็บและหลังบ้านรองรับหน้าจอมือถือ แท็บเล็ต และเดสก์ท็อป

## ข้อมูล

- ข้อมูลคิวถูกเก็บฝั่งเซิร์ฟเวอร์ใน `data/bookings.json`
- API ฝั่งลูกค้าเปิดเผยเพียงวันและเวลาที่ถูกจอง ไม่เปิดเผยชื่อเล่น ชั้น หรือเบอร์โทรศัพท์
- เบอร์โทรศัพท์ของลูกค้าแสดงเฉพาะในหลังบ้านสำหรับติดต่อกลับ
- สำรองข้อมูลโดยคัดลอกโฟลเดอร์ `data/`
- หากเปิดให้เข้าจากอินเทอร์เน็ตควรเพิ่มระบบป้องกันที่เหมาะสม

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |

| `preview-mobile.png` | ภาพตัวอย่างหน้าเว็บลูกค้าบนมือถือ |
| `preview-admin.png` | ภาพตัวอย่างหลังบ้าน |
